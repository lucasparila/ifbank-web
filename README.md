# IFBank Web

Frontend do sistema IFBank desenvolvido com Angular.

## Tecnologias

- Angular 21
- TypeScript
- Bootstrap 5
- RxJS

## Funcionalidades

- Login
- Cadastro de clientes
- Visualização de perfil
- Upload de foto de perfil

## Backend

O backend está disponível em:

https://github.com/lucasparila/ifbank-api

## Executando

```bash
npm install
ng serve
```

A aplicação ficará disponível em:

http://localhost:4200
